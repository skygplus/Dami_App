# Nigeria 2027 Election App

A lightweight campaign-style web app presenting seven reasons to unseat APC in the 2027 Nigerian election. It uses a clean, modern single-page design with navigation between each motivation step.

## Features

- Seven clear reasons for political change
- Interactive step-by-step card navigation
- Progress indicator
- Mobile-responsive layout
- Simple static HTML, CSS, and JavaScript setup

## Project files

- `index.html` – app structure
- `style.css` – styling and layout
- `script.js` – step content and navigation logic

## Run locally

From the project folder, start a simple local server:

```bash
cd /home/johns/Dami
python3 -m http.server 8000
```

Then open this in your browser:

```text
http://127.0.0.1:8000
```
